# Scientific Cutting Tools, Inc.

Welcome to the official GitHub organization for **Scientific Cutting Tools, Inc. (SCT)**, headquartered in **Simi Valley, California**. 

We specialize in the design and manufacture of high-precision carbide and high-speed steel cutting tools—including thread mills, port tools, boring bars, keyseat cutters, and specialty grooving tools—engineered for demanding aerospace, medical, automotive, and general machining applications.

---

## 🛠️ About This Organization

This GitHub space hosts our internal tooling, public utilities, engineering calculators, CAD/CAM data resources, and software integrations designed to support machinists, manufacturing engineers, and our internal development teams.

### What You'll Find Here
* **Internal & Open-Source Software:** Web tools, APIs, and automation scripts developed by the SCT engineering team.
